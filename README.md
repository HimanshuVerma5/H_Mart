# 🛒 GreenCart Mart

A modern full-stack e-commerce web application for buying groceries and daily essentials online.  
GreenCart Mart provides a seamless shopping experience with product browsing, cart management, and order handling.

---

## 🚀 Features

- 🔐 User Authentication (Login / Signup)
- 🛍️ Browse Products with clean UI
- 🔎 Search and Filter Products
- 🛒 Add to Cart / Remove from Cart
- 💳 Checkout System (Future Scope)
- 📦 Order Management
- ⚡ Fast and Responsive UI

---

## 🧑‍💻 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Redux Toolkit

### Backend
- Node.js
- Express.js

### Database
- MongoDB
